# 苹果快捷指令：截图 → 记账

本教程把 iPhone 的“截屏、识字、打开账本”串成一条自动流程：按一次系统截屏键，快捷指令从最新截图里读出金额，打开账本的公开 HTTPS 地址，并把金额预填到支出向导。第一次请从头做一遍；完成后只需正常截屏，再在网页里点几下即可入账。

> 文中的动作名称以中文 iOS 为准。不同 iOS 版本可能把“获取组”显示为“获取匹配文本中的组”，把“相簿”显示为“相册”，但字段含义相同。

## 一、先弄清楚截屏键为什么不能改

- **音量减键 + 侧边按钮**是 iPhone 的系统截屏组合键。
- 这不是“快捷指令”的可编程快捷键。两个硬件按钮被系统的 SpringBoard 在快捷指令之前直接接管，系统不会把这个按键事件交给第三方 App，也没有“重新绑定音量键/侧边键”的快捷指令动作。
- 因此不能把它改成“运行账本入账”，也不能让快捷指令截获这两个按键。辅助触控、轻点背面等方式最多只能提供另一种**触发截屏**的方法，不能改变系统组合键本身。
- 正确流程是：照常按 **音量减 + 侧边按钮**完成系统截屏；截图保存到“屏幕快照”相簿；再由自动化检测到“照片加入屏幕快照相簿”，运行下面的“账本入账”快捷指令。

“屏幕快照”在英文系统中通常叫 **Screenshots**。先打开“照片”App 确认这个相簿存在，并确认测试截图确实出现在里面。

## 二、先创建“账本入账”快捷指令

### 1. 新建快捷指令并命名

1. 打开 iPhone 的“快捷指令”App。
2. 点底部“快捷指令”，再点右上角“+”。
3. 点顶部名称，改成 **账本入账**，点“完成”。名称要记住，后面自动化要选择它。
4. 点“添加操作”，之后按下面的顺序逐个添加动作。不要把整段网址当成普通固定文字；金额和 OCR 结果必须插入为蓝色的“魔法变量”胶囊。

### 2. 动作一：查找最新的屏幕快照

1. 在“添加操作”的搜索框输入 **查找照片**，选择“查找照片”动作。
2. 在动作中点“添加过滤条件”（或“过滤条件”旁边的“+”）。设置为：
   - 第一个字段：**相簿**；
   - 第二个字段：**是**；
   - 第三个字段：**屏幕快照**。英文系统选择 **Screenshots**。
3. 点“排序依据”或“排序方式”，选择 **拍摄日期**；再选择 **最新在前**（有的版本显示为“降序”）。
4. 打开 **限制**，把数量填为 **1**。最终动作应表达为“查找相簿是屏幕快照的照片，按拍摄日期最新在前，限制 1 张”。
5. 这样做的原因是：自动化运行时相簿里可能有很多旧截图，限制为 1 张并取最新的一张，才能保证识别刚刚按键产生的截图。

### 3. 动作二：从图像提取文本

1. 点动作列表下方“添加操作”，搜索 **从图像提取文本**，选择它。
2. 动作的“图像”输入如果已经显示上一步的蓝色变量（通常显示“照片”），保持不动。
3. 如果输入是空白，点“图像”这个输入框，点键盘上方的“变量”或“选择变量”，在“快捷指令输入”/“上一个动作结果”中选择 **查找照片**的结果。
4. 不要手动输入文件名；必须使用“查找照片”的魔法变量。该动作的输出就是一段 OCR 全文，后面的“匹配文本”会使用它。

### 4. 动作三：用正则表达式匹配金额

1. 添加操作，搜索 **匹配文本**，选择“匹配文本”动作。
2. 点动作里的“文本”输入框，选择上一步 **从图像提取文本**的蓝色变量。
3. 点“模式”或“正则表达式”输入框，完整粘贴下面这一行（不要把反斜杠改成斜杠）：

   ```text
   (?:HK\$|HKD|￥|¥|\$)?\s*([0-9]{1,6}(?:\.[0-9]{1,2})?)\s*(?:元|港幣|港币)?
   ```

4. 确认“正则表达式”开关处于打开状态；如果界面只有一个“模式”输入框，直接把上面内容放进去即可。这个表达式的**第 1 组**是金额，能识别 `12`、`12.5`、`12.50`、`HK$12.50`、`¥12` 等写法。
5. 正则中的 `(?:...)` 是“不捕获的括号”，只有中间的 `(...)` 是捕获组。因此金额固定在**组 1**；不要再给币种外面加一层普通括号，否则组号会改变。
6. 若支付截图明确有“应付金额”或“实付金额”字样，可以把匹配范围收紧，例如先用 OCR 全文测试，再按截图文字改成更有上下文的模式。通用表达式可能把日期、余额或订单号中的数字当作金额，后面的排错部分有处理方法。

### 5. 动作四：获取第 1 组

1. 添加操作，搜索 **获取组**。如果搜不到，搜索 **获取匹配文本中的组**、**获取匹配文本**，选择能让你填写“组编号”的动作。
2. 把它的输入设为上一步“匹配文本”的蓝色结果。
3. 把 **组**或**组编号**设为 **1**。不要选 0：组 0 是整个匹配内容，可能包含 `HK$` 或“元”；组 1 才是纯金额。
4. 如果该动作默认只处理第一条匹配结果，保持默认即可。快捷记账只需要一个金额；通常应取 OCR 从前往后的第一条金额匹配。
5. 为了排查问题，可以临时在这里后面添加“显示结果”，运行一次快捷指令，确认显示的是 `12.50` 这样的纯数字。测试完成后可删除“显示结果”。

### 6. 动作五（推荐）：构造带金额的 URL

推荐只传金额，网址如下：

```text
https://haytham-fu.github.io/zhangben/?action=add&amount=变量
```

这里的“变量”不是要原样输入的文字，而是上一步“获取组”的蓝色魔法变量。按下面步骤制作：

1. 添加操作，搜索 **文本**，选择“文本”动作。
2. 在文本框先输入下面的固定部分：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&amount=
   ```

3. 把光标放在最后一个 `=` 后面，点键盘上方的“变量”或“选择变量”，选择上一步“获取组”的结果。成功后，金额会显示成蓝色胶囊，例如“获取组中的文本”，而不是灰色普通文字“变量”。
4. 最终文本动作应当是“固定网址 + 获取组的蓝色变量”。不要把 `AMOUNT`、`变量` 或 `12.50` 固定写死。
5. 推荐示例（实际运行时最后一段由魔法变量生成）：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&amount=12.50
   ```

纯数字金额本身不含空格或特殊字符，通常不需要 URL 编码；若金额变量中仍带有货币符号，先回到“获取组”检查是否误选了组 0。

### 7. 动作六：打开 URL

1. 添加操作，搜索 **打开 URL**，选择“打开 URL”动作。
2. 点它的 URL 输入框，选择上一步“文本”动作的蓝色结果。
3. 最终顺序应为：**查找照片 → 从图像提取文本 → 匹配文本 → 获取组 → 文本 → 打开 URL**。
4. 点右下角播放按钮手动测试。首次运行可能会询问照片权限、是否允许打开网址；选择允许。能在 Safari 打开账本并看到金额预填，说明快捷指令本身完成。

### 8. 传入币种或完整 OCR 的可选做法

账本未指定 `currency` 时按人民币处理。如果截图金额是港币，可以在固定网址后继续加入：

```text
&currency=HKD
```

完整示例：

```text
https://haytham-fu.github.io/zhangben/?action=add&amount=12.50&currency=HKD
```

若不想在快捷指令中自己提取金额，也可以把 OCR 全文交给网页解析。做法如下：

1. 在“从图像提取文本”之后，添加 **URL 编码**动作（有的版本显示为“对文本进行 URL 编码”）。
2. 把它的输入设为“从图像提取文本”的蓝色全文变量。中文、换行、空格、`&` 等字符都要经过这个动作，不能直接拼到网址里。
3. 添加“文本”动作，先输入：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&text=
   ```

4. 把光标放在最后一个 `=` 后面，插入 **URL 编码**动作的蓝色结果；再添加“打开 URL”，输入选择这个“文本”动作的蓝色结果。
5. 最终网址类似：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&text=Paid%20HK%2412.34
   ```

   网页会从 `text` 的 OCR 全文中取第一个像金额的数字；因此这是一种备用方案。如果全文前面有日期、订单号或余额，优先使用“获取组”后传 `amount=变量`，准确性更好。

## 三、创建“照片加入屏幕快照相簿”自动化

快捷指令建好后，再让系统在新截图进入相簿时自动运行它。

1. 打开“快捷指令”App，点底部 **自动化**。
2. 点右上角 **+**，选择 **创建个人自动化**。如果页面直接显示自动化条件，继续下一步。
3. 在触发条件中选择 **照片**。
4. 选择 **照片加入相簿**（部分版本显示“照片被添加到相簿”），再点相簿字段，选择 **屏幕快照**；英文系统选择 **Screenshots**。
5. 点“下一步”，选择 **运行快捷指令**动作。
6. 点动作里的“快捷指令”字段，选择刚才创建的 **账本入账**。
7. 点“下一步”检查摘要：触发条件应是“照片加入屏幕快照”，执行动作应是“运行账本入账”。
8. 关闭 **运行前询问**。出现“确定不询问吗？”时点 **不询问**或“不要询问”。这样截屏后不会每次弹确认框。
9. “运行时通知”若有该选项，可以按个人喜好保留或关闭；它不影响记账。点“完成”保存。

注意：今后任何被加入“屏幕快照”相簿的照片都会触发此自动化，不只是在付款 App 里截的图。如果不希望某张图入账，截完后不要把它放进这个相簿，或先关闭自动化。第一次测试建议手动截一张只含清晰金额的图。

## 四、打开后在账本里完成记账

快捷指令只负责识别金额和打开页面，不会替你猜分类，也不会绕过确认。Safari 打开链接后，网页会读取 `action=add`，进入“支出”记账向导，并把 `amount`（或从 `text` 解析出的金额）填入金额框；读取完后网址上的查询参数会被清掉，刷新页面不会重复触发同一笔。

按页面顺序完成：

1. **选择支出类型**：选择实际类别，例如吃饭、交通、日用品等。
2. **选择付款方式**：选择现金、银行卡、八达通或页面中实际使用的方式。
3. 检查金额、币种和备注；如果金额不对，先取消，不要直接确认。
4. 点 **确认**，记录才会写入本机账本，并同步更新总览、预算和流水明细。

如果链接里只传 `amount`，默认币种是人民币；需要港币时加入 `currency=HKD`。如果金额为空或不是大于 0 的数字，页面会要求重新输入。

## 五、常见问题排查

### 1. 链接跑到了微信，不在 Safari 打开

- 在微信里看到的页面不是快捷指令理想的运行环境；把网址复制后，用 Safari 地址栏打开。
- 检查默认浏览器：较新的 iOS 在“设置 → App → 默认 App → 浏览器 App”中选择 **Safari**；较旧版本可在“设置 → Safari → 默认浏览器 App”中选择 Safari。
- 快捷指令里的动作必须是系统的 **打开 URL**，不要使用微信专用的打开链接动作，也不要把 `weixin://` 放进网址。

### 2. 没有照片、提取文本失败或提示没有权限

- 打开“设置 → 隐私与安全性 → 照片 → 快捷指令”，允许访问照片；若系统提供“所有照片”，选择它。
- 在“照片”App 确认截图确实位于“屏幕快照”相簿。若使用了别的相簿，回到“查找照片”动作把相簿改成实际名称。
- 手动打开“账本入账”运行一次并按提示允许权限；然后重新测试自动化。自动化本身不会绕过首次授权。
- OCR 需要图片里有足够大的清晰文字。模糊、反光、深色背景或金额被遮挡时，先换一张清晰截图。

### 3. 金额识别成日期、余额或订单号

- 在“从图像提取文本”后临时加入“显示结果”，查看手机实际 OCR 文本；再在“匹配文本”后临时加入“显示结果”，查看匹配到的完整内容。
- 确认“匹配文本”的输入是 OCR 全文，而不是“查找照片”的结果；确认“获取组”的组编号是 **1**，不是 0。
- 通用正则会匹配 OCR 中遇到的第一段数字。若截图有“余额 100.00、实付 12.50”，应把正则改为只匹配“实付/应付”附近的数字，或裁剪截图后再识别。
- 不要在正则里给币种加普通捕获括号；本教程的金额必须保持在第 1 组。检查无误后删掉临时“显示结果”动作。

### 4. 打开的页面没有预填金额

- 检查“文本”动作中 `amount=` 后面是否是蓝色的“获取组”魔法变量，而不是手动输入的“变量”二字。
- 检查“打开 URL”的输入是否引用了“文本”动作的蓝色结果，而不是重新手填了不完整的网址。
- 在 Safari 地址栏查看最终网址：应看到 `?action=add&amount=12.50` 这类查询参数。若传的是完整 OCR，必须看到经过编码的 `text=` 内容。
- URL 里有中文或完整 OCR 时，务必先使用“URL 编码”动作；未编码的 `&` 会被网页当成新的参数，可能截断文本。

### 5. 页面还是旧版本，像是 PWA 缓存

- 在 Safari 打开公开网址后下拉刷新；必要时彻底关闭 Safari，再重新打开网址。
- 若刚部署过新版本，进入“设置 → App → Safari → 高级 → 网站数据”，搜索 `haytham-fu.github.io`，删除该站点数据后重新打开网址。不同 iOS 版本菜单名称可能略有差异。
- 删除网站数据会同时清除该站点保存在本机的账本数据；操作前先在账本的设置中导出 JSON 备份。不要为了排查缓存直接清除数据而不备份。
- 查询参数被页面消费后会从地址栏清掉，这是正常现象，不代表金额没有传入；看记账向导的金额框即可确认。

## 六、局域网备用方案（简短）

公网 HTTPS 地址不可用时，手机和电脑连接同一 Wi-Fi，把固定网址临时换成：

```text
http://电脑局域网IP:5174/?action=add&amount=变量
```

把端口改成实际开发端口，并在电脑防火墙放行；手机上不要写 `localhost`，因为那指向手机自己。公网地址恢复后，应改回 HTTPS 网址。
