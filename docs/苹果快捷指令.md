# 苹果快捷指令：截图 → 记账

用 iPhone「快捷指令」识别支付截图中的金额，打开账本的公开 HTTPS 网址，并进入记账向导预填金额。

## 1. 先了解截图快捷键

- **音量减 + 侧边按钮**是 iPhone 的**系统截图**组合键。
- 这个组合由 iOS 系统占用，快捷指令**不能重新绑定或接管**它。
- 正确做法是：照常按组合键截图，再用自动化「**照片加入屏幕快照相册**」运行快捷指令。

截图会出现在「屏幕快照」相册；英文系统通常显示为 **Screenshots**。

## 2. 创建自动化

1. 打开「快捷指令」App →「自动化」→「创建个人自动化」。
2. 选择照片相关触发条件「**照片加入屏幕快照相册**」（不同 iOS 版本的文案可能略有不同）。
3. 添加动作「运行快捷指令」，选择下文创建的「账本入账」。
4. 按需关闭「运行前询问」，然后保存自动化。

## 3. 创建「账本入账」快捷指令

按以下顺序添加动作（名称可能随 iOS 版本略有差异）：

1. **查找照片**：相簿选「屏幕快照」/ **Screenshots**，按拍摄日期最新优先，限制为 1 张。
2. **从图像提取文本**：输入使用上一步找到的最新截图。
3. **匹配文本/金额**：从 OCR 结果中匹配金额，并将匹配结果保存为 `AMOUNT` 变量。例如可用：
   - `([0-9]+(?:\.[0-9]{1,2})?)`
   - `(HK\$|¥|\$)?\s*([0-9]+(?:\.[0-9]{1,2})?)`
4. **打开 URL**：使用下面的公开 HTTPS 地址，把 `AMOUNT` 替换为快捷指令中的金额变量。

### 公开 HTTPS 地址（首选）

网址基准：

```text
https://haytham-fu.github.io/zhangben/
```

带金额的深层链接：

```text
https://haytham-fu.github.io/zhangben/?action=add&amount=AMOUNT
```

也可以加入可选参数（值需要进行 URL 编码）：

- `currency=HKD`、`currency=RMB` 或 `currency=USD`
- `note=备注文字`
- `text=原始 OCR 全文`（适合把整段 OCR 结果传给网页解析）

例如：

```text
https://haytham-fu.github.io/zhangben/?action=add&amount=12.34&currency=HKD&note=%E5%8D%88%E9%A4%90
```

如果只传 OCR 原文：

```text
https://haytham-fu.github.io/zhangben/?action=add&text=Paid%20HK%2412.34
```

在「打开 URL」动作中，`AMOUNT`、`note` 或 `text` 应使用前面动作产生的变量；不要把变量名当成普通文字固定写入。

## 4. 打开链接后完成记账

打开深层链接后，网页会进入「记账」向导，金额已经预填。按顺序：

1. 选择**支出类型**；
2. 选择**付款方式**；
3. 检查预填金额（以及币种、备注），点击**确认**完成记账。

## 5. 局域网备用方案

公开 HTTPS 网址是首选。若暂时无法访问公网，也可以让手机与电脑连同一局域网，并把 URL 换成本机开发服务地址，例如：

```text
http://YOUR_MAC_IP:5174/?action=add&amount=AMOUNT
```

将 `YOUR_MAC_IP` 换成电脑的局域网 IP，将 `5174` 换成实际端口；不要在手机上使用 `localhost`。这是备用方案，仍需确保防火墙放行端口。
