# 苹果快捷指令：截图 → 记账

用 iPhone「快捷指令」把支付截图里的金额送到本机账本网页，自动打开支出向导并预填金额。

> 需要电脑与手机在同一局域网，并已用 Vite 开发服（或局域网可访问的地址）打开账本。默认端口以实际为准，下文以 `5174` 为例。

---

## 1. 系统截图快捷键（硬件）

- **音量减 + 侧边按钮** = 系统截图（锁屏侧键机型常见组合）。
- 该组合由系统占用，**快捷指令无法重新绑定**同一物理组合。
- 做法：让系统照常截图 → 用「照片加入相册」自动化触发快捷指令。

截图通常会进入相册中的 **「屏幕快照」**（英文系统多为 **Screenshots**）相簿。

---

## 2. 创建自动化

1. 打开 **快捷指令** App → **自动化** → **创建个人自动化**。
2. 选择 **相册** / **照片** 相关触发（文案因系统版本略有差异）：
   - **当照片加入相册** → 选择 **「屏幕快照」** / **Screenshots**。
3. 下一步动作：**运行快捷指令** → 选下面建好的「账本入账」快捷指令。
4. （可选）关闭「运行前询问」，或保留询问以免误触发。
5. 保存自动化。

---

## 3. 创建快捷指令「账本入账」

建议步骤（可按系统版本微调动作名称）：

1. **查找照片**  
   - 相簿 = 「屏幕快照」/ Screenshots  
   - 排序 = 最新优先  
   - 限制 = 1  
2. **从图像提取文本**（输入为上一步照片）。  
3. （推荐）**匹配文本** / 正则，从 OCR 结果里取出金额，例如：  
   - `([0-9]+(?:\.[0-9]{1,2})?)`  
   - 或带货币：`(HK\$|¥|\$)?\s*([0-9]+(?:\.[0-9]{1,2})?)`  
4. **打开 URL**，指向本机账本的 Network 地址，例如：

```text
http://YOUR_MAC_IP:5174/?action=add&amount=AMOUNT
```

### 占位符请替换

| 占位符 | 含义 |
|--------|------|
| `YOUR_MAC_IP` | Mac 在局域网中的 IP（系统设置 → 网络；或看 Vite 终端里的 Network URL） |
| `AMOUNT` | 上一步匹配到的金额变量 |
| `5174` | 实际端口（以 Vite / 部署端口为准） |

可选查询参数：

- `currency=HKD` / `RMB` / `USD`（默认 RMB）
- `note=备注文字`（需 URL 编码）
- `text=原始OCR全文`：若未带 `amount`，网页会尝试从 `text` 解析**第一个**金额样式数字

示例：

```text
http://192.168.1.23:5174/?action=add&amount=12.34&currency=HKD&note=%E8%B6%85%E5%B8%82
```

或只传 OCR 原文：

```text
http://192.168.1.23:5174/?action=add&text=Paid%20HK%2412.34
```

---

## 4. 网页上完成记账

打开链接后，账本会：

1. 切到 **记账** Tab  
2. 打开支出向导，并预填金额（及币种/备注，若有）  
3. 从 **支出类型** 开始 → **扣款方式** → **确认金额/备注并保存**  
4. 消费完查询参数后会清掉 URL，避免刷新重复触发  

你只需点选：**支出类型 → 扣款方式 → 确认保存**。

---

## 5. 常见问题

- **打不开页面**：确认手机与 Mac 同一 Wi‑Fi；防火墙放行端口；用 Vite 打印的 **Network** 地址，不要用 `localhost`（手机访问不到）。  
- **金额不对**：在快捷指令里收紧正则，或改传 `text=` 让网页解析。  
- **HTTPS / 公网**：若以后部署到 HTTPS 域名，把 URL 换成该域名即可；快捷指令同样适用。
