# 苹果快捷指令：音量下 + 侧边键 → 截屏 → 入账

本教程说明如何用 iPhone **系统截屏键**触发记账。推荐直接导入现成包，再按自动化文档完成设置。

- **现成包目录**：[`docs/shortcuts/`](./shortcuts/)（含 `账本入账.shortcut`）
- **自动化逐步指南（必读）**：[`docs/shortcuts/自动化设置.md`](./shortcuts/自动化设置.md)
- **包说明 / 签名**：[`docs/shortcuts/README.md`](./shortcuts/README.md)
- **公开网站**：https://haytham-fu.github.io/zhangben/

---

## 一、硬性结论：按键怎么触发记账

### Apple 不允许把该组合键直接绑到快捷指令

- **音量减键 + 侧边按钮**（有的机型叫电源键）是 iPhone 的 **系统截屏**组合键。
- 系统（SpringBoard）在快捷指令之前接管这对硬件键；**没有**「重新绑定音量键/侧边键去运行快捷指令」的官方能力。
- 「快捷指令」App、个人自动化、辅助触控、背面轻点，都 **不能** 把这一对键改成「直接运行账本入账」。

若导入快捷指令后只按键却「没有反应」，通常不是快捷指令坏了，而是 **还没建「屏幕快照」相册自动化**，或 **没关掉「运行前询问」**。

### 唯一支持、且真正使用这对按键的路径

```text
① 用户按下 音量下 + 侧边键
② 系统完成截屏（唯一能响应这对键的系统行为）
③ 截图写入「照片」→ 相簿「屏幕快照 / Screenshots」
④ 个人自动化「照片加入相册 → 屏幕快照」立即运行「账本入账」
   （必须关闭「运行前询问」）
⑤ 快捷指令：获取最新屏幕快照 → OCR → 打开账本网址预填
```

**因此：触发键就是音量下 + 侧边键；机制是「截屏 → 相册自动化」，不是「按键直达快捷指令」。**  
请按这个模型设置；下文与现成包都按此设计。

「屏幕快照」在英文系统中为 **Screenshots**。先打开「照片」确认该相簿存在，且测试截图会出现在里面。

## 二、推荐做法：导入现成快捷指令 + 建自动化

1. 从仓库获取 [`docs/shortcuts/账本入账.shortcut`](./shortcuts/账本入账.shortcut)。
2. 传到 iPhone，用「快捷指令」打开并添加。  
   - 若提示未签名 / 无法打开：在 Mac 上执行  
     `shortcuts sign --mode anyone --input 账本入账.shortcut --output 账本入账-已签名.shortcut`  
     再导入已签名文件（详见 [shortcuts/README.md](./shortcuts/README.md)）。
3. **必须**按 [自动化设置.md](./shortcuts/自动化设置.md) 创建「照片加入屏幕快照」自动化，并 **关闭运行前询问**。
4. 手动运行一次「账本入账」，允许照片权限与打开网址。
5. 任意界面截一张屏：数秒内应出现「正在打开账本…」并打开网站。

现成包动作顺序：

1. 注释（说明按键限制）  
2. **获取最新的屏幕快照**（数量 1；比「查找照片」更可靠）  
3. 从图像提取文本  
4. URL 编码  
5. URL = `https://haytham-fu.github.io/zhangben/?action=add&text=` + 编码结果  
6. 显示通知「正在打开账本…」  
7. 打开 URL  

网页从 `text=` 解析金额并打开支出向导；你再选类型、付款方式并确认。

## 三、手动创建「账本入账」（可选）

若无法导入 `.shortcut`，可在手机上手工搭建。动作名称以中文 iOS 为准；不同版本「相簿/相册」「获取组」等用词可能略有差异。

### 1. 新建并命名

1. 打开「快捷指令」→ 右上角「+」。
2. 名称改为 **账本入账**。
3. 按下面顺序添加动作；变量必须是蓝色「魔法变量」胶囊。

### 2. 动作一：注释（建议）

添加「注释」，写明：按键不能直绑；须用「屏幕快照」自动化；关闭运行前询问。

### 3. 动作二：获取最新的屏幕快照（推荐）

1. 搜索 **获取最新的屏幕快照** / **Get Latest Screenshots**。
2. 数量设为 **1**。

这比「查找照片 + 过滤相簿」更稳：自动化触发时相册可能尚未完成索引，但「最新屏幕快照」通常立刻可用。

（备选）若坚持用「查找照片」：过滤「相簿是屏幕快照」，按拍摄日期最新在前，限制 1 张。

### 4. 动作三：从图像提取文本

1. 搜索 **从图像提取文本**。
2. 「图像」选上一步「最新屏幕快照」的蓝色变量。

### 5. 动作四～六：URL 编码 → 构造网址 → 打开

推荐把 **OCR 全文**交给网页解析（与现成包一致）：

1. 添加 **URL 编码**，输入为 OCR 全文变量。
2. 添加 **URL**（或「文本」）动作，内容为：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&text=
   ```

   在 `=` 后插入 **URL 编码** 的蓝色结果。
3. （可选）添加 **显示通知**，正文：`正在打开账本…`。
4. 添加 **打开 URL**，输入为上面的 URL 变量。

最终网址类似：

```text
https://haytham-fu.github.io/zhangben/?action=add&text=Paid%20HK%2412.34
```

### 6. 进阶（可选）：在快捷指令里用正则抽金额

若希望只传纯金额 `amount=`，可在 OCR 后增加：

1. **匹配文本**，正则（组 1 为金额）：

   ```text
   (?:HK\$|HKD|￥|¥|\$)?\s*([0-9]{1,6}(?:\.[0-9]{1,2})?)\s*(?:元|港幣|港币)?
   ```

2. **获取组**，组编号 **1**（不要选 0）。
3. 构造：

   ```text
   https://haytham-fu.github.io/zhangben/?action=add&amount=
   ```

   后接「获取组」蓝色变量，再「打开 URL」。

港币可追加 `&currency=HKD`。通用正则可能误匹配日期/余额；付款截图建议优先「实付/应付」附近数字，或继续用 `text=` 交给网页解析。

### 7. 手动测试快捷指令

点播放：允许照片与打开网址权限；应能打开账本。这只证明快捷指令本身可用——**还不等于截屏键会触发**。

## 四、创建「照片加入屏幕快照」自动化（必做）

**没有这一步，按音量下+侧边键永远不会跑快捷指令。**

完整逐步（含权限、关闭询问、排错）见：

→ **[shortcuts/自动化设置.md](./shortcuts/自动化设置.md)**

摘要：

1. 快捷指令 → 自动化 → 创建个人自动化。  
2. 触发：**照片** → **照片加入相簿** → **屏幕快照**。  
3. 动作：**运行快捷指令** → **账本入账**。  
4. **关闭「运行前询问」**，并确认「不询问」。  
5. 完成保存。  

任何新进入「屏幕快照」的照片都会触发；不需要记账时可暂时关闭该自动化。

## 五、打开后在账本里完成记账

快捷指令只负责识别与打开页面，不会替你猜分类。Safari 打开后，网页读取 `action=add`，进入支出向导，并把 `amount`（或从 `text` 解析的金额）填入；参数消费后会从地址栏清除，刷新不会重复同一笔。

1. 选择支出类型。  
2. 选择付款方式。  
3. 检查金额、币种、备注。  
4. 点 **确认** 写入本机账本。

未指定 `currency` 时按人民币；港币请加 `currency=HKD`。金额无效时需手填。

## 六、常见问题排查

### 1. 按音量下+侧边键「完全没反应」

按 [自动化设置.md 第 6 节清单](./shortcuts/自动化设置.md) 逐项勾选。最高频原因：

1. **没建自动化**（只导入了快捷指令）。  
2. **「运行前询问」仍开启**。  
3. 照片权限未给「快捷指令」。  
4. 相簿名不是「屏幕快照 / Screenshots」。  
5. 截屏其实没成功（照片里没有新图）。

记住：系统不会把该组合键发给快捷指令；没反应时先查 **截屏是否进相册 + 自动化是否在跑**。

### 2. 链接跑到了微信，不在 Safari 打开

- 用 Safari 打开；检查默认浏览器为 Safari。  
- 动作必须是系统 **打开 URL**，不要用微信专用动作或 `weixin://`。

### 3. 没有照片、提取文本失败或没有权限

- **设置 → 隐私与安全性 → 照片 → 快捷指令** → 所有照片。  
- 确认图在「屏幕快照」。  
- 手动运行一次快捷指令完成授权。  
- OCR 需要清晰大字；模糊/反光先换图。

### 4. 金额识别成日期、余额或订单号

- 临时「显示结果」查看 OCR 与匹配。  
- 用正则时确认组编号为 **1**。  
- 或改回 `text=` 全文交给网页；必要时裁剪截图。

### 5. 打开的页面没有预填金额

- 确认 `amount=` / `text=` 后是蓝色变量。  
- `text=` 必须先 URL 编码。  
- 看地址栏是否含查询参数；消费后参数消失是正常的，看向导金额框。

### 6. 页面还是旧版本（PWA 缓存）

- Safari 下拉刷新或彻底关掉再开。  
- 必要时清除该站网站数据（**先导出账本 JSON**，否则本地数据会丢）。

## 七、局域网备用方案（简短）

公网不可用时，手机与电脑同一 Wi-Fi，把网址临时换成：

```text
http://电脑局域网IP:5174/?action=add&amount=变量
```

不要用 `localhost`（指向手机自己）。恢复后改回 HTTPS。
