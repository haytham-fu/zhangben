# 账本入账 · 苹果快捷指令包

## 硬性限制（请先读）

**Apple 不允许快捷指令绑定「音量下 + 侧边/电源键」。**

这对按键只属于系统截屏，快捷指令 / 自动化 / 辅助功能都**不能**改绑成「直接运行某条快捷指令」。  
若有人告诉你「可以把音量下+侧边键直接绑到快捷指令」，那是错的。

### 唯一可用、且真正用到这对按键的路径

1. 你按下 **音量下 + 侧边键** → iPhone **系统截屏**
2. 截图进入相册 **「屏幕快照」**（英文：**Screenshots**）
3. 个人自动化 **「照片加入相册 → 屏幕快照」** 立刻运行快捷指令 **「账本入账」**
4. 必须 **关闭「运行前询问」**，否则每次都会卡住、看起来像「没反应」

**所以：触发键就是那对硬件键；触发机制是「截屏 → 相册自动化」，不是「按键直达快捷指令」。**

详细逐步说明见同目录 **[自动化设置.md](./自动化设置.md)**。完整背景与排错见上级 **[苹果快捷指令.md](../苹果快捷指令.md)**。

## 快捷指令做什么

名称：**账本入账**

1. **注释**：说明上述按键限制与正确触发方式  
2. **获取最新的屏幕快照**（数量 = 1；比「查找照片」更稳）  
3. **从图像提取文本**（OCR）  
4. **URL 编码** OCR 全文  
5. 构造网址：`https://haytham-fu.github.io/zhangben/?action=add&text=` + 编码结果  
6. **显示通知**「正在打开账本…」（确认自动化确实跑了）  
7. **打开 URL**（Safari 打开账本并预填）

网页会从 `text=` 里解析金额，进入支出向导；你再选类型 / 付款方式并确认。

## 导入到 iPhone

1. 把 `账本入账.shortcut` 传到手机（隔空投送 / iCloud / 邮件附件等）。
2. 用「快捷指令」App 打开该文件 → 点 **添加快捷指令**。
3. 若系统提示「无法打开未签名的快捷指令」或导入失败，见下方 **签名**。
4. 导入后 **必须** 再按 [自动化设置.md](./自动化设置.md) 建自动化；**只导入快捷指令、不建自动化 = 按截屏键不会有任何反应。**

### 签名（本包在 Linux 生成，通常未签名）

iOS 15+ 往往只接受已签名的 `.shortcut`。本仓库在 Linux 上构建，**没有 Mac 的 `shortcuts` 命令，无法在此签名**。

在 **Mac**（已登录同一 Apple ID、已装「快捷指令」）上执行：

```bash
shortcuts sign --mode anyone --input 账本入账.shortcut --output 账本入账-已签名.shortcut
```

再把 `账本入账-已签名.shortcut` 隔空投送到 iPhone 导入。

若你愿意在手机上手动重建同等动作，也可对照 [苹果快捷指令.md](../苹果快捷指令.md)，不必依赖签名文件。

## 一分钟自检

1. 自动化已创建，且 **关闭「运行前询问」**。  
2. 「设置 → 隐私与安全性 → 照片 → 快捷指令」允许访问照片。  
3. 手动打开一次「账本入账」并允许打开网址。  
4. 任意界面按 **音量下 + 侧边键** 截一张屏。  
5. 数秒内应出现通知「正在打开账本…」，并打开账本网站。

若没有：优先看 [自动化设置.md](./自动化设置.md) 里的「没反应」排查清单。
