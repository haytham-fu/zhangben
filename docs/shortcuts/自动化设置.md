# 自动化设置：音量下 + 侧边键 → 账本入账

本文是 **iPhone 逐步操作**。请按顺序做完；只导入快捷指令而不建自动化，按截屏键会「没反应」。

---

## 0. 先弄清机制（必读）

**Apple 不允许快捷指令绑定「音量下 + 侧边/电源键」。**

这对键只会触发 **系统截屏**。没有「把该组合键改成运行快捷指令」的开关。

正确链路（触发键仍然是那对硬件键）：

```text
按下 音量下 + 侧边键
        ↓
   系统截屏成功
        ↓
截图进入「照片」→ 相簿「屏幕快照」（Screenshots）
        ↓
个人自动化「照片加入相册 → 屏幕快照」被触发
        ↓
立刻运行快捷指令「账本入账」（关闭「运行前询问」）
        ↓
OCR → 打开 https://haytham-fu.github.io/zhangben/?action=add&text=...
```

请接受这个模型。下面所有步骤都是为了把这条链路打通。

---

## 1. 导入或确认快捷指令「账本入账」

1. 打开「快捷指令」App。
2. 确认已有名为 **账本入账** 的快捷指令（从本目录 `账本入账.shortcut` 导入，或按上级文档手动创建）。
3. **手动点一次运行**（播放按钮）：
   - 若弹出 **照片** 权限 → 选 **允许** / **所有照片**（不要选「无」）。
   - 若弹出 **打开网址** / Safari → 选 **允许**。
   - 应看到通知「正在打开账本…」（若已包含该动作），并打开账本网站。
4. 若手动运行都失败，先不要建自动化；先修好快捷指令本身。

### 照片权限（极易漏）

到系统设置再确认一次：

1. 打开 **设置 → 隐私与安全性 → 照片**。
2. 找到 **快捷指令**。
3. 选择 **所有照片**（或至少能读到「屏幕快照」相簿）。  
   选「无」或未授权时，自动化会静默失败，看起来像「没反应」。

---

## 2. 确认「屏幕快照」相簿存在

1. 打开 **照片** App。
2. 底部点 **相簿**。
3. 在「媒体类型」或相簿列表中找到 **屏幕快照**（英文系统：**Screenshots**）。
4. 任意界面按一次 **音量下 + 侧边键**，确认新图出现在该相簿最上方。

若截图进了别的相簿、或「屏幕快照」不存在，自动化条件会对不上。

---

## 3. 创建个人自动化（核心）

### 3.1 新建

1. 打开 **快捷指令** App。
2. 点底部 **自动化**。
3. 点右上角 **+**（或「创建个人自动化」）。
4. 选择 **创建个人自动化**（不要选家庭自动化）。

### 3.2 触发条件：照片加入「屏幕快照」

1. 在触发列表中找到并点 **照片**（有的版本在「事务」或向下滚动）。
2. 选择 **照片加入相簿** / **照片被添加到相簿**。
3. 点 **相簿** 字段，选择 **屏幕快照**（英文：**Screenshots**）。  
   **不要**选「最近项目」「收藏」或其他自定义相册。
4. 点 **下一步**。

### 3.3 动作：运行「账本入账」

1. 点 **添加操作**，搜索 **运行快捷指令**，选中。
2. 点动作里的 **快捷指令** 字段，选择 **账本入账**。
3. 确认摘要类似：  
   - 当：**照片加入「屏幕快照」**  
   - 执行：**运行「账本入账」**
4. 点 **下一步**（部分版本直接进入开关页）。

### 3.4 必须关闭「运行前询问」

1. 找到开关 **运行前询问**（Ask Before Running）。
2. **关闭它**。
3. 系统弹出「确定不询问吗？」→ 点 **不询问** / **不要询问**。

**这是「没反应」最常见原因。**  
开着「运行前询问」时，截屏后可能只在通知栏闪一下或毫无体感，自动化不会真正跑完。

可选：

- **运行时通知**：可开可关；本快捷指令已自带「正在打开账本…」通知。
- 点 **完成** 保存。

### 3.5 确认自动化已启用

回到「自动化」列表，确认该条目：

- 触发：照片加入屏幕快照  
- 动作：运行账本入账  
- **未**显示需要每次询问  
- 开关为开启状态（若有总开关）

---

## 4. 首次运行授权（Safari / 打开 URL）

自动化第一次真正打开网页时，系统可能再问一次：

- 「快捷指令」要打开此网址？→ **允许**
- 是否允许「快捷指令」使用 Safari？→ **允许**

建议：

1. 先在「快捷指令」里 **手动运行一次「账本入账」**，把照片与打开 URL 权限都点掉。
2. 再截一张屏测自动化。

默认浏览器尽量用 **Safari**（设置 → App → 默认 App → 浏览器 App，或旧版「设置 → Safari」）。

---

## 5. 测试（应在数秒内打开网站）

1. 锁屏或回到桌面均可；打开任意 App 也可以。
2. 同时按住 **音量下 + 侧边键**，松开后应看到截屏动画 / 缩略图。
3. **等待约 1～5 秒**（相册写入 + 自动化启动）：
   - 应出现通知：**正在打开账本…**
   - Safari（或默认浏览器）应打开：  
     `https://haytham-fu.github.io/zhangben/?action=add&text=...`
4. 页面进入支出向导；金额若已解析会预填，再选类型 / 付款方式 → 确认。

**通过标准：** 任意截屏后数秒内打开账本网站（不必是付款截图；先测链路通不通）。

---

## 6. 「没反应」排查清单（按顺序勾）

截屏后完全没动静时，逐项检查：

### A. 按键与截屏本身

- [ ] 按的是 **音量下 + 侧边键**（不是音量上；不是电源长按；不是截屏手势未开）。
- [ ] 屏幕出现了截屏动画 / 左下角缩略图。
- [ ] 打开「照片」→「屏幕快照」，**最新一张就是刚才那张**。

### B. 自动化条件

- [ ] 「快捷指令 → 自动化」里存在该个人自动化。
- [ ] 触发是 **照片加入相簿**，相簿是 **屏幕快照 / Screenshots**（拼写、系统语言一致）。
- [ ] 动作是 **运行快捷指令 → 账本入账**（名称完全一致）。
- [ ] **「运行前询问」已关闭**，并点过「不询问」。
- [ ] 自动化未被删除、未关闭。

### C. 权限

- [ ] **设置 → 隐私与安全性 → 照片 → 快捷指令** = 所有照片（或足够权限）。
- [ ] 手动运行「账本入账」时不再弹权限框、能打开网页。
- [ ] 首次打开 URL 已点过「允许」。

### D. 快捷指令本身

- [ ] 手动点「账本入账」运行：能出通知并打开网站。
- [ ] 动作使用的是 **获取最新的屏幕快照**（数量 1），不是过期的「查找照片」错误过滤。
- [ ] 打开的是公网地址 `https://haytham-fu.github.io/zhangben/`（手机能上网）。

### E. 系统干扰

- [ ] 低电量模式 / 屏幕使用时间限制未阻止「快捷指令」。
- [ ] Focus / 勿扰一般仍会跑自动化，但通知可能被压住；以是否打开网页为准。
- [ ] 刚截完立刻连按多次截屏，可能连触发；先测 **单次** 截屏。
- [ ] 企业 MDM / 屏幕时间「限制 App」是否限制了快捷指令或 Safari。

### F. 仍失败时的最小复现

1. 删除并重建自动化（再关一次「运行前询问」）。  
2. 手动运行「账本入账」确认成功。  
3. 只截一张屏，盯着通知与 Safari。  
4. 若手动成功、截屏仍无：几乎一定是自动化条件/询问开关/相册名问题。

---

## 7. 使用注意

- **任意**进入「屏幕快照」的新图都会触发（含误触截屏）。不想记账时，可暂时关掉该自动化，或忽略打开的网页。
- 快捷指令**不会**自动保存账目；网页里仍需你确认支出类型与付款方式。
- OCR 依赖截图清晰度；模糊、反光、金额过小可能导致金额不准，可在网页里改。
