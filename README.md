# 账本

通用记账 Progressive Web App（PWA）。移动优先、简体中文、本地持久化，无需登录。

公网默认为**普通账本**（可改预算；日计划对照默认关闭）。个人 3500+1500 / 期初汇总等请用独立配置包导入（见「设置 → 导入个人计划配置」），站点本身不携带个人计划文件。

更新摘要见 [CHANGELOG.md](./CHANGELOG.md)。

## 本地运行

```bash
cd zhangben
npm install
npm run dev
```

浏览器打开终端提示的本地地址（一般为 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

## 添加到主屏幕（安装 PWA）

构建并部署到 HTTPS（或本机 `preview`）后，可用浏览器安装。开发模式下部分浏览器对 Service Worker 支持有限，建议用 `build` + `preview` 或部署后体验安装。

### iPhone / iPad（Safari）

1. 用 **Safari** 打开网站（需 HTTPS 或 localhost）。
2. 点底部分享按钮（方框带向上箭头）。
3. 下滑选择 **「添加到主屏幕」**。
4. 名称确认为「账本」后点 **添加**。
5. 从主屏幕图标打开，即可全屏独立使用。

### Android（Chrome）

1. 用 **Chrome** 打开网站。
2. 点右上角 **⋮** 菜单。
3. 选择 **「安装应用」** 或 **「添加到主屏幕」**。
4. 确认安装后，可从桌面/应用抽屉打开。

主题色：`#3b82f6`（蓝色）。图标与 Web App Manifest 已随构建生成。

## 预算规则摘要

| 项目 | 说明 |
|------|------|
| 基础 / 专项 | 默认 3000 + 1000，可在记账顶栏修改；也可导入个人计划包 |
| 日计划对照 | 默认关闭（纯记账）；开启后日历显示日计划余缺与节奏建议 |
| 周六模式 | 开启计划对照后，可在总览切换「出去玩 / 不玩」 |
| 期初汇总 | 可选 `monthOpening`（仅通过导入计划配置加载，不随站点分发） |
| 特例（请客） | 计入总额；建议可切换「含特例 / 不含特例」 |

## 汇率与预算

- 基础币种 **RMB**；另支持 HKD / USD / EUR / JPY / GBP / TWD / MOP / SGD。
- 可在「记账」页顶栏选最多 **4 个偏好币种**；录入时优先展示。
- **实时 / 固定**汇率；实时失败回退固定或缓存。每笔保存原币 + 汇率 + 折合 RMB。
- 基础/专项月预算也在记账顶栏调整（设置页仅保留提示与其它偏好）。

## 截图 OCR 入账（主流程）

1. 打开「记账」→ 默认进入 **截图识别入账**。
2. 选择来源：八达通（默认 HKD）或一般账单；可一次上传多张图片。
3. 等待本地 OCR（Tesseract.js，中英；首次需联网下载语言包）。
4. 在复核列表中勾选、改日期/金额/分类/支付方式；充值默认标为 **不计支出**。
5. 点 **确认导入** 后才写入账本。手动录入与文本批量作为备用。

支付方式可选：八达通、微信支付、支付宝、银行卡、信用卡、其他。

## 八达通规则

- 消费按 **HKD** 录入，按汇率折合 RMB，可标支付方式（八达通 / 微信 / 支付宝 / 银行卡 / 信用卡 / 其他）。
- **充值不计支出**：选「八达通充值」，或批量粘贴时备注含「充值」——记入流水但不计入预算支出。
- 支持批量粘贴：每行 `金额 备注` 或 `日期 金额 备注`；备注含洗衣/空调/吃饭等会尝试自动分类。

## 小荷包

- 创建只需 **名称 + 颜色**；金额通过「转入」从本月总预算剩余存入（可选手选基础/专项剩余）。
- 系统荷包 **小钱猪**：点「月末结算」将盈余转入，或超支扣除（余额可为负表示欠小钱猪）。
- 记账时可关联小荷包，支出会扣减该荷包余额。

## 界面

- 全站液态玻璃（卡片 / 底栏 / 弹层 / 按钮 / 输入框 / 建议模块）；底栏切换有滑动玻璃胶囊。
- 按钮与芯片均为大圆角 / 胶囊形；配色主题 + 静态/动态背景。
- 开启计划对照后，日计划与月度预算使用进度条；颜色：安全偏蓝绿 → 临近橙 → 超支橙红 → 严重超支红。

## 数据

全部保存在浏览器 **localStorage**。可在「设置」导出 / 导入 JSON 备份，或清空本地数据。

## 技术

- React + TypeScript + Vite
- `vite-plugin-pwa`（manifest + Service Worker）
